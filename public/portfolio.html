Sentra – Media Bias & Hallucination Analysis Platform
GitHub
Python · FastAPI · React · Large Language Models · RAG · NLP

An AI-driven platform that analyzes news articles for media bias and generative hallucinations. The system uses a Retrieval-Augmented Generation (RAG) pipeline integrated with LLMs to cross-reference multiple news sources simultaneously, neutralizing single-source echo-chamber effects.

  • Engineered a RAG pipeline to synthesize data across publishers, preventing single-source bias during summarization
  • Implemented NLP sentiment polarity analysis and media framing keyword detection to score source alignment
  • Built a dynamic grounding mechanism that constrains model outputs to validated facts, reducing hallucination rates
