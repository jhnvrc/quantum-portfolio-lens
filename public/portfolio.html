Sentra – Media Bias & Hallucination Analysis

GitHub
Python, FastAPI, React, Large Language Models, RAG, NLP

Sentra is an AI-driven platform I developed to analyze news articles for media bias and generative hallucinations. At its core, the system utilizes a Retrieval-Augmented Generation (RAG) pipeline integrated with large language models to cross-reference multiple news sources concurrently, actively neutralizing echo-chamber effects.

  • Engineered the RAG pipeline to synthesize data points across publishers, preventing single-source bias during summarization.
  • Programmed Natural Language Processing algorithms to perform sentiment polarity analysis and detect specific framing keywords.
  • Built a dynamic grounding mechanism into the generation layer that firmly constrains the model's outputs to validated facts, minimizing hallucinations.

HeartGuard Pro – Cardiac Risk Predictor

GitHub
React, TypeScript, Python, Machine Learning, FastAPI

I developed HeartGuard Pro as a cardiovascular risk assessment tool aimed at processing clinical data. The backend relies on a machine learning classification model that I trained and tuned using a dataset of over 70,000 patient records to calculate the likelihood of cardiovascular disease based on demographics, vital signs, and biochemistry results.

  • Trained and optimized a predictive machine learning classifier focused on multi-variable diagnostic data handling.
  • Designed a supplementary rules engine that contextualizes raw physiological data—like blood pressure and cholesterol—against established medical thresholds.
  • Connected the FastAPI processing logic to a React dashboard, delivering continuous, low-latency health reports complete with confidence scoring metrics.

BISINDO Sign Language Recognition

Python, YOLOv8, YOLOv11, Computer Vision, React

This research-focused computer vision project was aimed at evaluating state-of-the-art object detection models for real-time Indonesian Sign Language (BISINDO) translation. I handled the entire pipeline from custom dataset curation to real-time inference optimization for the web.

  • Curated, annotated, and pre-processed a custom imagery dataset representing 26 unique BISINDO hand gestures.
  • Conducted extensive comparative performance testing between YOLOv8 and YOLOv11 architectures, achieving over 95% mAP50 accuracy on gesture detection.
  • Integrated the accelerated YOLOv11 inference model into a web-based React application, providing users with responsive webcam feedback for interactive learning.

Study Buddy – AI Learning Monitor

GitHub
React, TypeScript, FastAPI, OpenCV, MediaPipe

Study Buddy is an intelligent tutoring web application I built to help monitor student focus metrics during self-directed study sessions. It leverages in-browser computer vision and deep learning biometric identification to replace standard authentication and provide automated focus tracking.

  • Architected a biometric facial recognition login system powered by a custom MiniFaceNet deep learning model that I trained using Triplet Loss.
  • Integrated MediaPipe with OpenCV to continuously calculate head pose estimation and eye gaze vectors.
  • Developed a Python-based rule expert system that parses temporal distraction metrics to issue personalized feedback and automated break recommendations.

Gold Analytics – AI Trading Prediction

Live App GitHub
React, TypeScript, Python, LSTM Neural Networks, REST API

For my software engineering capstone, I developed a quantitative analysis platform that provides predictive insights and technical charting for the XAU/USD gold market, combining deep learning techniques with traditional market analysis.

AI Image Processing Platform

GitHub
React, Python, TensorFlow, Computer Vision, FastAPI

This web application serves as a comprehensive suite for AI-driven image editing, wrapping several complex deep learning models into a streamlined user interface. Because the operations are computationally intensive, I engineered a GPU-accelerated backend to handle processing securely.

  • Implemented a U-Net architecture to perform automatic background and object removal with detailed edge mask refinement.
  • Incorporated ESRGAN (Enhanced Super-Resolution Generative Adversarial Networks) to facilitate 4x automated image upscaling without artifact degradation.
  • Designed neural style transfer features utilizing VGG19 feature extraction, allowing art-based resynthesis of user images via REST API coordination.
